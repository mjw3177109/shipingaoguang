# BasketCut AI 开发阶段与验收门槛

## V0.1 已交付（CPU 基础可用版）
- Django 球馆隔离、登录、比赛上传与 FFprobe 格式/时长检查
- FFmpeg 音频强度峰值片段建议，候选可改时间、填球员并审核
- 后台任务 Worker，FFmpeg 生成 720P/30fps 无声混剪 / 指定球员片段
- 仅身份授权用户访问原片和下载，支持删除原片/结果
- Docker Compose 一键启动，CI 检查和后端测试

**注意**：音频峰值仅用于降低拖动时间轴的工作量；可能大量误报和漏报。不得营销为自动识别进球。

## V0.2 视觉研发（Kaggle/Colab 免费 GPU 只用于实验）
1. 只用有授权的篮球视频构建验证集（不同角度、光线、球衣、遮挡）。
2. 实验可合法商用的球员、篮筐、篮球检测模型；审查训练权重许可证。
3. 视频抽帧 → 篮筐附近球运动候选 → 时间窗口 → 人工确认。
4. 指标：候选召回率、每 10 分钟误报数、每小时处理时长、云计算费用。
5. 对比 V0.1 音量候选，务必记录漏剪片段。
6. 免费环境不作为生产 Worker。录像不得公开上传到 GitHub。

## V0.3 云端 GPU 工作器
- 抽象 `analyze(video_uri, event_sink, job_id, config)`。
- 输出标准 JSON：`{"start_seconds":12.3,"end_seconds":25.1,"source":"visual_proposal","score":0.76,"notes":"basket-near-rim"}`。
- 后端只存“候选”，必须人工通过才能用于导出。
- 队列幂等、任务超时、失败重试、算力自动停止，限价开关和按店结算。
- 私有对象存储短时效 URL、容器隔离、禁止敏感日志和跨租户访问。

## V1.0 付费球馆试点验收
- 1 场 30–60 分钟 1080P 固定机位赛事，完整可交付。
- 10 场以上多光照场景验证；主观精彩度由球馆人工打分。
- 分析节省的人审时间 > 50% 为试点目标，而非功能保证。
- 单用户、球队和个人素材权限清晰；录制及传播取得授权。
- 清晰的保留期限、删除/导出机制、审计和安全评估。
- 扫码领取使用有到期时间与权限控制的链接，**不可公开列出所有球员视频**。
