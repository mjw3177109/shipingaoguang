# BasketCut V0.7 — 快速人工标注、逐帧二次复核与可追溯数据导出

## 核心目标

V0.6 已能在真实公开视频上把 **合成观测轨迹**导入 Django、经过模拟审核并用 FFmpeg 输出 MP4，但并没有证明篮球专项模型有用。V0.3 仅有四帧人工目视确认的球框，且独立视频测试 TP=0、FP=110、FN=2。V0.7 继续补真实标注数据闭环，不虚构新训练数据或准确率。

## 实际新增

1. **下一帧连续标注**：进入比赛→篮球框标注→CPU 智能抽帧；框选球或确认无球后点击“保存并跳下一待审帧”，页面跳转到下一条尚未处理的建议。
2. **回看原框**：已标注记录中的“看图 / 填入旧框”会在视频帧上显示当时保存的框/无球状态，便于再次核对（不能由算法替代人工判断）。
3. **逐帧二次复核**：新增每帧 `quality_verified`、复核时间、复核账号。人工回看画面确认后点击“已目视复核此帧”；每次编辑会自动取消复核状态。撤销复核、编辑或删除都撤销该比赛训练许可确认。
4. **大数据集分页**：每页 50 帧，能继续访问历史标签，不再被原页面 500 条硬截断。
5. **严格导出模式**：`--verified-only --three-way` 只允许经过二次复核、重新确认训练授权、至少 6 场不同比赛的数据进入 YOLO 三集合导出。未复核的比赛直接失败，不会被静默当作无球样本。
6. **质量追溯**：`manifest.json` 每个帧记录 `quality_verified` 和审核人 ID，`quality_report.json` 记录二次复核完成量。已有 V0.5 模型评测只有在标注全复核时才允许进入人工评审阶段；`production_release` 始终为 false。
7. **真实早期数据体检**：旧版公开许可两段视频四帧目视标注不具有二次复核记录、也无无球负样本；在 V0.7 质量报告中明确 **未达到门槛**。真实视频素材使用 Coentor（CC BY-SA 3.0）和 Benoît Prieur（CC0）来源，测试期下载，不提交原片。

## 使用步骤

启动 Django 及原有 Worker（无需额外 GPU 或在线 AI API）：

```powershell
git checkout main
git pull origin main
docker compose up -d --build
```

在网页按以下操作：上传比赛→生成待审帧→框选篮球/明确无球→保存并跳下一张→在“人工二次复核”列表点击看图核对→逐项复核→填写训练权利依据重新确认授权。

**严禁批量一键“复核全部”。** 这个按钮表示人工目视确认，不是算法给出的真假标签。已经存在的历史标签默认未复核，是为了避免历史数据在用户不知情时被宣称通过新审核。

只在可信服务器上由管理员执行：

```bash
python manage.py audit_ball_labels --owner-id 1
python manage.py export_ball_dataset \
  --owner-id 1 --out /tmp/basketcut-v07 \
  --three-way --verified-only
python -m highlights.vision.review_readiness_v07 \
  --manifest /tmp/basketcut-v07/manifest.json \
  --out /tmp/basketcut-v07/review_readiness.json
```

正常 `export_ball_dataset` 的旧双集合模式依然存在，不强制启用 V0.7 严格模式，避免破坏已有开发数据。

## 进入正式模型评测的初始门槛

- 完整不同比赛数量建议至少 8 场（最少 6 场方可生成 train/val/test）。
- 人工篮球正例不少于 120 帧，明确人工无球负例不少于 40 帧。
- 所有用于对比的已导出图片必须具有复核人和复核确认记录；仍需留出完全独立比赛进行盲测。
- 橙色球衣、广告、木地板、篮圈等误检场景优先作为难负样本；但球被遮挡并不自动等于无球。
- 检测框 IoU、F1 / Recall 和投篮候选召回率必须分开评估：**有了模型检测框并不代表检测到了投篮，更不代表判断进球成功。**

**警告：**“已二次复核”是用户明确的审核操作记录，系统无法仅凭点击证明人工确实看过完整画面；素材训练授权、肖像与隐私合规也仍需另行确认。

## CI 实战与授权

- Django 业务逻辑测试使用临时文件/模拟视频，验证权限、复核状态、数据导出。
- `v07-real-annotation-quality.yml` 下载真实公开视频、提取旧版四帧样本，并运行 V0.7 质量审查。这里不会声称老样本得到新增人工复核，也不会拿四帧宣传准确率。
- V0.7 没有任何研究权重自动升级生产的代码。
